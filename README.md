# ZeroEngine 0.6.0

ZeroEngine — браузерный прототип игрового движка. Проект запускается из `index.html` и публикуется через GitHub Pages.

## Структура проекта

```text
ZeroEngine/
├── index.html                  # Точка входа для браузера и GitHub Pages
├── VERSION.txt                 # Версия проекта
├── LICENSE                     # Лицензия проекта
├── .nojekyll                   # Отключает обработку Jekyll на GitHub Pages
├── assets/
│   ├── icons/                  # Иконки приложения
│   ├── models/                 # Модели (GLB/GLTF и другие)
│   ├── textures/               # Текстуры
│   ├── materials/              # Материалы
│   ├── audio/                  # Звуки
│   └── skyboxes/               # Skybox-текстуры
├── src/
│   ├── css/styles.css          # Стили интерфейса
│   └── js/app.js               # Логика редактора, сцены и ZeroBox
└── docs/
    └── THIRD-PARTY-NOTICES.md  # Уведомления о сторонних библиотеках
```

Импортируемые во время работы ресурсы хранятся внутри проекта в браузере и включаются в ZIP-экспорт. Папки `assets/*` предназначены для ресурсов, которые пользователь хочет хранить рядом с исходниками, например в GitHub-репозитории.

## Запуск

### Локально

Открой папку проекта через локальный HTTP-сервер. Например, в VS Code используй расширение Live Server. Прямой запуск через `file://` не рекомендуется: браузер может заблокировать ES-модули и локальные ресурсы.

### GitHub Pages

1. Создай репозиторий и загрузи в него **содержимое** этой папки, сохранив структуру каталогов.
2. Открой `Settings → Pages`.
3. Выбери `Deploy from a branch`, ветку `main` и папку `/ (root)`.
4. Сохрани настройки и открой опубликованный GitHub Pages URL.

Для Three.js и JSZip используется CDN, поэтому при первом запуске требуется интернет.

## Что есть в 0.6.0

### Сцена и освещение
- В новой сцене нет стартовых источников света.
- Удалены legacy-объекты `Ambient Light`, `Default Light`, `Startup Light` и `Key Light`, если они были сохранены как стартовые источники старых сборок. Пользовательские источники света сохраняются.
- Нет `AmbientLight`, `DirectionalLight` или других источников света, автоматически добавляемых редактором. Источники появляются только после добавления пользователем.
- Карта теней отключена; все меши не отбрасывают и не принимают тени.
- При отсутствии пользовательских источников света редактор показывает модели в полноярком режиме без искусственного освещения. У примитивов исходный материал — Standard, поэтому добавленный пользователем свет освещает их в редакторе и игровом просмотре.
- Skybox можно добавить отдельно; по умолчанию окружение `scene.environment` пустое.

### Физика и коллизии
- Отдельное окно «Редактор коллизии»: Box, Sphere, Capsule, размеры, смещение, Trigger и включение/отключение.
- `Player` получает капсульную коллизию и физику по умолчанию.
- Новые примитивы и модели получают включённые коллайдеры. Для примитивов размеры соответствуют геометрии. При первом открытии старых проектов включаются только стандартные неотредактированные коллайдеры 1×1×1; пользовательские формы и размеры остаются без изменений.
- Для импортируемых моделей коллайдер автоматически подгоняется по локальным границам модели. После ручной правки его размеры больше не перезаписываются автоматикой.
- Гравитация, скорость, масса и линейное затухание; симуляция выполняется в Play Mode.
- Движение разделяется по осям и проверяет пересечение пути, чтобы быстрый объект не пролетал сквозь тонкий коллайдер.
- Есть опора на уровень земли `Y = 0`.
- Sphere/Capsule и повёрнутые коллайдеры для физических расчётов пока приближаются осевыми AABB-границами. Это базовая система, а не полноценный физический движок.
- Коллайдер Trigger не блокирует движение.

### ZeroBox
- Большое свободное поле для блоков и соединений.
- Перетаскивание блоков из библиотеки, объектов из иерархии, ZeroBox из файловой панели.
- ЛКМ по пустому месту, ПКМ или средняя кнопка мыши — панорамирование. Блоки при этом не сдвигаются; их можно перемещать за заголовок. На телефоне поле можно перемещать свайпом.
- Позиция прокрутки сохраняется после редактирования, добавления и удаления блоков.
- Провод удаляется нажатием/касанием по линии или правой кнопкой мыши.
- Копирование и вставка выбранных блоков вместе с внутренними соединениями.
- Help с краткими описаниями блоков.

### Проекты и файлы
- Создание, локальное хранение, ZIP-импорт и ZIP-экспорт проектов.
- Исходники организованы по папкам `src`, `assets` и `docs`.
- Внутри редактора есть папки ассетов, сцены, скрипты, текстуры, модели и ZeroBox.

### Тестовый режим
- Изменения во время Play Mode не записываются в проект.
- При выходе проект восстанавливается из снимка до запуска теста.

## Импорт Blender

Предпочтительный формат — **GLB**: он надёжнее сохраняет геометрию, UV, PBR-материалы и встроенные текстуры. Для GLTF с внешними текстурами и бинарными файлами импортируй всю папку. Для OBJ импортируй OBJ, MTL и связанные текстуры вместе. Файл `.blend` напрямую не открывается; экспортируй его через Blender `File → Export → glTF 2.0 → GLB`.

## Известные ограничения

- Это ранний браузерный прототип, а не готовый коммерческий движок.
- Физика пока не включает полноценный rigid-body solver, трение, вращательную динамику, joint/constraint-систему, точную mesh-коллизию и динамический обмен импульсом между телами.
- Поворот коллайдеров не учитывается в AABB-расчёте.
- В ZeroBox передача исполнения по проводам реализована раньше универсальных типизированных data-портов.
- Нет сетевой игры, компилятора игровых сборок и нативного экспорта.
- Полное тестирование на всех браузерах и телефонах ещё не проводилось.

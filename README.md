# ZeroEngine 0.8.0

ZeroEngine — ранний браузерный прототип игрового движка с 3D-сценой, редактором UI и визуальной логикой ZeroBox. Точка входа — `index.html`; проект можно публиковать через GitHub Pages.

## Запуск

### Локально

Открой папку через локальный HTTP-сервер (например, Live Server в VS Code). Запуск через `file://` не рекомендуется: браузер может блокировать ES-модули и локальные ресурсы.

### GitHub Pages

1. Создай репозиторий и загрузи в корень **содержимое** этой папки.
2. Открой `Settings → Pages`.
3. Выбери `Deploy from a branch`, ветку `main` и папку `/ (root)`.
4. Сохрани настройки и открой опубликованный URL.

Для Three.js, загрузчиков моделей и JSZip используются внешние CDN, поэтому для запуска требуется интернет.

## Что входит в 0.8.0

### 3D-сцена и объекты

- Примитивы: Cube, Sphere, Plane, Circle, Cylinder, Cone, Capsule, Torus, Torus Knot, Ring, Tube, Pipe, Pyramid, Wedge, Stairs, Tetrahedron, Octahedron, Icosahedron и Dodecahedron.
- Вкладка `＋` добавляет объекты по категориям: геометрия, игровые объекты, камеры/окружение и свет.
- Отдельный объект Skybox; его текстура назначается через свойства объекта.
- Добавляемые пользователем Point, Directional и Spot Lights. Стартовые источники света отсутствуют.
- В редакторе нет автоматического освещения и карт теней. Сетка и оси скрываются в Play Mode.
- Камеры: изометрическая (ортографическая) и свободная (перспективная). В сцене видны линии поля обзора камеры.
- Отдельный 3D-редактор камеры с gizmo перемещения, вращения и масштаба; отдельный 3D-редактор коллизии.
- Импорт моделей GLB/GLTF, FBX, OBJ/MTL, STL и PLY; для Blender рекомендуется GLB.
- Масштаб импортируемых моделей можно корректировать по единицам измерения. Текстуры и PBR-материалы GLB/GLTF сохраняются лучше всего.

### Камера и управление

- На ПК в Play Mode обзор вращается мышью: клик по сцене захватывает мышь (Pointer Lock), доступен запасной режим перетаскивания.
- На телефоне добавь `CameraControlArea` в UI Designer. Это специальная сенсорная зона, которая считывает свайпы как движения мыши и управляет обзором камеры.
- `Player` может использовать камеру в голове, за спиной или с собственным смещением.
- `Player Start` — отдельная точка появления, скрытая в игровом режиме по умолчанию.
- `Joystick` в UI Designer создаёт или использует две переменные `Numericarray` для X/Y и вызывает `JoystickMoved`, пока джойстик отклонён.

### UI Designer

- Элементы интерфейса: Button, Text, Scale, Slider, Background, CameraControlArea и Joystick.
- Элементы размещаются на 16:9-макете и появляются на игровом экране.
- Button поддерживает залипание, назначение клавиши клавиатуры, `Buttonclicked`, `Buttonpressed` и `ButtonResting`.
- `Buttonpressed` повторно запускает цепочку, пока клавиша или кнопка удерживается.
- Text, Scale и Slider могут быть связаны с переменными проекта.

### ZeroBox — визуальная логика

- Отдельное большое поле для блоков, входов/выходов и проводов.
- Блоки можно размещать в любом месте, двигать, соединять и удалять.
- Навигация по полю: ЛКМ по пустому месту, ПКМ или средняя кнопка — панорама; колесо и кнопки масштаба — zoom; свайп на телефоне — панорама.
- Выделение связанной сети, групповое копирование/вставка с внутренними соединениями и массовое удаление.
- Поиск блоков по названию и Help с кратким описанием.
- `Walking` удалён из библиотеки; старые блоки `Walking` автоматически преобразуются в `Moving`.
- `Moving` перемещает выбранный объект по координатам, направлению или силе. `Speed` задаёт множитель движения.
- `Gamespeed` управляет игровым временем: 0 — пауза, 1 — нормальная скорость, до 5 — ускорение.
- События: `Straightaway`, `Buttonclicked`, `Buttonpressed`, `ButtonResting`, `JoystickMoved`.
- Среди действий и логических блоков: `Moving`, `Speed`, `Squat`, `Jumpup`, `Life`, `Number`, `Numericarray`, `Minus`, `Plus`, `Divide`, `Multiply`, `Size`, `Writes`, `Laser`, `Change`, `Loop`, `Branching`, `ForkYesorno`, `ChangeTransparency`, `ChangeColor`, `ChangeTexture`, `ChangeModel`, `Changesound`, `Playsound`, `Don'tSound`, `Pausesound`, `Changinganimation`, `Twist`, `Collision`, `Physics`, `Close` и другие.
- Собственные переменные создаются через `＋`: Number, Numericarray, Yesorno, Transparency, Color. Numericarray хранит одно изменяемое число и подходит для HP, стамины, энергии и других значений. Арифметические блоки изменяют исходную переменную.
- Блоки и связи можно копировать (`Ctrl+C` / `Ctrl+V`), выделять сеть и удалять группой.

### Физика и коллизии

- Базовая физика: гравитация, скорость, масса в килограммах и линейное затухание.
- Коллайдеры Box, Sphere и Capsule; настройка включения, размеров, смещения и Trigger.
- Player получает капсульную коллизию и не должен проходить через включённые препятствия.
- Физика и тестирование пока не заменяют полноценный rigid-body solver: сложные и повёрнутые формы аппроксимируются простыми границами, нет полноценных joints, трения и вращательной динамики.

### Проекты и сохранение

- Создание проектов, локальное хранение в браузере, ZIP-импорт и ZIP-экспорт.
- Проектные файлы разложены по папкам `assets`, `src` и `docs`.
- Play Mode работает на снимке проекта: изменения во время теста не сохраняются, при выходе состояние до запуска восстанавливается.

## Импорт из Blender

Рекомендуемый формат — **GLB**: он лучше всего переносит геометрию, UV, PBR-материалы и встроенные текстуры. Для GLTF с внешними ресурсами импортируй всю папку. Для OBJ импортируй OBJ, MTL и текстуры вместе. Файл `.blend` напрямую не открывается; в Blender используй `File → Export → glTF 2.0 → GLB`.

## Ограничения прототипа

- Сетевой мультиплеер, компилятор игровых сборок и нативный экспорт пока не реализованы.
- Физика упрощённая: без полноценного обмена импульсами между телами, точной mesh-коллизии, joints и вращательной динамики.
- ZeroBox в этой версии прежде всего управляет последовательностью выполнения; универсальные типизированные data-порты ещё развиваются.
- Полное интерактивное тестирование на всех браузерах и мобильных устройствах не проводилось.
